# Estudo historico swing-v1 (2024–2025)

Este e um resultado efetivamente obtido pelo backtest Python legado para o
periodo 02/01/2024–30/12/2025. **Nao e backtest dos EAs MQL5 A ou B**, que nao
foram executados no Strategy Tester.

- `RELATORIO.md`: metodologia, operacoes, comparadores e limitacoes.
- `summary.json`: metricas agregadas do relatorio.
- `result.json`: ledger, curvas e detalhes da simulacao.
- `comparison.html`: visualizacao comparativa produzida pelo mesmo estudo.
- `intraday.audit.json`: auditoria M1 limitada, sem mudar os resultados.
- `data/sources.json`: proveniencia e hashes das fontes.
- `config/backtest.protocol.json` (na raiz do repositorio): protocolo do estudo.

Os dados brutos historicos e caches de cotacoes foram omitidos; os arquivos
publicados nao bastam para reproduzir integralmente o estudo.
